Pre-acceptance defect and correction
- Initial hardware run stopped at PLATFORM: FAIL stage=RX_ONLY error=-5.
- Root cause: the application was configured for FDD, while the RX-only guard required ENSM_MODE_RX readback.
- Correction: accept FDD and independent-FDD readback after RXB selection and maximum TX attenuation; preserve the RX transition/readback path for non-FDD operation.
- The regression test reproduced the old failure as FDD prepare actual=-5 expected=0 before the correction.
